# GradeGuard n8n- 2025

AI-assisted first-pass essay grading and feedback workflow built with n8n, featuring rubric-based assessment, automated writing metrics, structured feedback, and instructor alerts.

GradeGuard automates the first-pass assessment of written assignments using instructor-defined rubrics, objective writing metrics, and a large language model.

The project is designed to reduce feedback delays while maintaining instructor oversight. The current version is a working prototype. A future development phase will add confidence-based routing and structured human review.

## Current Workflow

1. A student submits an essay through a custom HTML portal.
2. The submission is sent to an n8n webhook.
3. Required fields, email format, and essay length are validated.
4. The matching assignment rubric is retrieved from Google Sheets.
5. A JavaScript node calculates objective writing metrics.
6. An LLM evaluates the essay against the rubric.
7. The structured result is parsed and validated.
8. Results are logged and feedback is sent to the student.
9. The instructor receives operational alerts through Telegram.
10. A separate global error workflow records unexpected failures.

## Importing the Workflows

1. Download the JSON files from the `workflow` directory.
2. Import them into your n8n instance.
3. Configure your own credentials for:
   - Groq
   - Google Sheets
   - Gmail
   - Telegram
4. Replace all placeholder values with your own configuration.
5. Connect the global error handler through the n8n workflow settings.
6. Activate the workflows only after completing testing.

## Frontend Configuration

Open:

```text
frontend/essay-submission-portal.html
```

Replace:

```javascript
const WEBHOOK_URL = "YOUR_N8N_WEBHOOK_URL";
```

with the webhook URL generated by your own n8n workflow.

## Security and Privacy

The repository contains sanitised templates only.

It does not include:

- API keys
- OAuth tokens
- Private credential values
- Real student submissions
- Private email addresses
- Active Google Sheet identifiers
- Active Telegram chat identifiers

Do not upload real student data or unredacted workflow exports to a public repository.

## Current Limitations

- LLM-generated scores may vary across repeated evaluations.
- The current version does not yet calculate a formal confidence score.
- Teacher approval is not yet required before feedback is sent.
- The workflow has not yet been evaluated against a large human-scored dataset.
- Automated writing metrics are limited indicators and should not be treated as direct measures of writing quality.

## Planned Improvements

## Intended Use

GradeGuard is an educational technology prototype for AI-assisted first-pass feedback. It is intended to support teachers rather than replace professional academic judgement.
